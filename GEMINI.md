# Project Guidelines & Preferences

## Code Style & Formatting
- **HTML / JSX Tags**: Prefer a single line for an HTML/JSX tag wherever possible (avoid breaking attributes or opening/closing tags across multiple lines unless strictly necessary).

## Editor & Agent Behavior
- **File Management**: Do not open files in editor tabs after modifying them.

## UI & Styling
- **No Heavy Decorations**: Do not use blur effects (`backdrop-blur`, `blur-*`), heavy drop-shadows, or expensive frontend decorations.
- **Optimization**: Keep UI lightweight, minimal, and fast. Avoid unnecessary libraries, complex modals, and decorative bloat.
